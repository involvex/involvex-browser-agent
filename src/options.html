Involvex AI — Settings

Keys are stored locally on this device only (chrome.storage.local) and sent directly to the provider you choose. No Involvex server is involved.

Google Gemini

Get a key at aistudio.google.com/apikey

OpenAI

Get a key at platform.openai.com/api-keys

Anthropic Claude

Get a key at console.anthropic.com

OpenRouter

One key, hundreds of models (incl. free ones). Get a key at openrouter.ai/keys

OpenCode Zen

OpenAI-compatible. Free models end with -free, e.g. mimo-v2.5-free. Use Load models for the full live list.

Custom (OpenAI-compatible)

For OpenCode, Kilo Code, LM Studio, vLLM, LiteLLM, or any server that exposes /v1/chat/completions.

Local (Ollama)

Run a small local model, e.g. ollama pull qwen2.5:3b. For vision: ollama pull llava:7b. Start with OLLAMA_ORIGINS=* ollama serve so the extension can reach it. For RAG embeddings: ollama pull nomic-embed-text.

FastVLM (LiteRT local)

Download FastVLM-0.5B.litertlm. Python 3.10+ required for the PC bridge. On Android, run a local server on the phone (HostAI or flutter_litert_lm) — see docs/FASTVLM-SETUP.md.

Appearance

Theme for the chat panel and this settings page.

System prompts

Base instructions sent with every request. Distinct from the prompt library chips below. Page context (Ask) and tool docs (Agent) are still appended automatically.

Prompt library

These become the quick-prompt chips on the New chat screen. Edit the label (chip text) and the prompt that gets sent. Leave both empty to remove a row.

Agent sites

Auto-enable or block Agent mode by hostname (one domain per line). Deny wins over allow. Leave empty for manual toggle only.

Page RAG

On long pages, retrieve only the most relevant excerpts instead of sending the full text. Uses local TF-IDF by default; enable Ollama embeddings for better accuracy.

Backup & Sync

Back up your bookmarks, extension settings and installed-extension list to a private GitHub Gist. Serverless and free — no Involvex or third-party server. API keys are never included in a backup.

Extensions from backup

These were installed on your other device. Extensions can't be reinstalled automatically — tap to open each one's install page.

    Create a token at github.com/settings/tokens → Fine-grained or classic with only the gist scope. Restore adds bookmarks into a new "Involvex Restore" folder (it never overwrites existing bookmarks).

    File Backup

    Export a complete backup file including API keys and all settings. Store this file securely — it contains your API keys.

    Error log

    Recent errors from chat and agent runs (newest first, max 50). Errors also appear inline in the chat. Use this to diagnose provider or connection problems.
